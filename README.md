# 不太灵的女巫 V51｜综合型童话养成

以 V50 为基础继续开发，保留已有森林探索、魔法制作、伙伴关系、收藏馆、花房、月光小镇与 moonlightV3 存档。

## V51：冬日森林与雪绒兔
- 解锁图鉴中原本标注“未来版本开放”的雪绒兔，使用仓库中已有的角色美术素材。
- 冬季探索达到开放条件后，前往月影水潭即可触发一次专属相遇，不需要反复刷概率。
- 两种不同的相遇选择，各自带来不同材料奖励；完成后雪绒兔永久加入森林伙伴名单。
- 雪绒兔会出现在森林图鉴、伙伴小天地和小屋访客列表中，可继续互动、送礼、邀请来访。
- 冬季森林加入飘雪视觉效果与独立的轻柔冬风环境音；其他季节的天气与探索加成不变。
- 森林生态卡片会在冬季提示雪绒兔的相遇地点；已经结识后显示完成状态。
- 不重置已有存档，不修改已有伙伴的亲密等级与收集记录。

## V50：童话天气与环境声
- 小屋、森林、工坊、月光小镇按场景切换环境音。
- 环境音与背景音乐独立开关、独立音量。
- 薄雾、晴夜、细雨、萤光夜有不同的视觉和声音氛围。
- 天气表现读取森林每日生态；森林奇遇页与主场景使用同一套天气。

## V49：童话音乐与月光收藏馆
- 小屋、森林、工坊、星夜四组原创场景旋律。
- 背景音乐可独立开关和调节音量。
- 三格月光陈列台、作品初见日期、专属发现故事和八件作品里程碑。

## 运行
打开 GitHub Pages 游戏主页即可游玩；也可以在电脑上用 Chrome / Edge 打开 `index.html`。
完整可编辑项目由 `index.html` 与 `assets/` 目录组成。
