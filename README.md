# 不太灵的女巫 V49｜综合型童话养成

以 V48 完整项目为基础继续开发，保留原有美术素材、森林主线、花房订单、墨团每日陪伴、魔法研究台、伙伴系统与 moonlightV3 存档。

## V49：童话音乐与月光收藏馆

### 原创场景音乐
- 小屋：温柔的八音盒与钢琴感旋律。
- 月光森林：更空灵、神秘的星雾旋律。
- 魔法工坊：轻巧的魔法铃音。
- 星夜剧情：舒缓、带一点未知感的童话叙事旋律。
- 使用浏览器 Web Audio 实时合成原创旋律，不加载外部音乐文件。
- 玩家主动点击顶部「开启童话音乐」后播放；支持音量调节和关闭。
- 切换场景时自动切换主题，不会每次点击都重新启动整首音乐。

### 月光收藏馆
- 新增三格月光陈列台，可展示最喜欢的三件魔法作品。
- 记录作品首次制作日期与专属发现故事。
- 收藏馆纳入魔法研究台解锁的两种隐藏配方。
- 新增八件作品的完整收藏里程碑。
- 旧存档自动兼容，不需要重新开始游戏。

## 运行
打开 GitHub Pages 游戏主页即可游玩；也可以在电脑上用 Chrome / Edge 打开 index.html。
完整可编辑项目由 index.html 与 assets/ 目录组成。
