# 不太灵的女巫 V50｜综合型童话养成

以 V49 完整项目为基础继续开发，保留原有美术素材、森林主线、花房订单、墨团每日陪伴、魔法研究台、伙伴系统与 moonlightV3 存档。

## V50：童话天气与环境声

### 每日天气视觉
- 小屋、森林等场景统一读取森林每日生态天气，不再各自随机显示互相矛盾的天气。
- 薄雾：增加流动雾气与柔化月光。
- 晴夜：增加稀疏星光。
- 细雨：增加雨丝效果。
- 萤光夜：增加更明亮的萤火与漂浮光点。
- 森林奇遇页与森林主场景使用同一套天气表现。

### 原创环境音
- 小屋：低声壁炉噼啪声，随天气叠加窗外雨声、夜虫声或薄雾风声。
- 森林：树间微风；细雨时加入雨声；晴夜和萤光夜加入轻微虫鸣。
- 工坊：轻柔坩埚气泡声。
- 月光小镇：远处风铃与夜风。
- 使用浏览器 Web Audio 实时合成，不加载外部音频文件。
- 环境音与背景音乐独立开关、独立音量；需要玩家主动开启，兼容浏览器的音频交互限制。
- 切换场景时平滑切换环境声层。

## V49：童话音乐与月光收藏馆
- 小屋、森林、工坊、星夜四组原创场景旋律。
- 背景音乐可独立开关和调节音量。
- 三格月光陈列台、作品初见日期、专属发现故事和八件作品里程碑。

## 运行
