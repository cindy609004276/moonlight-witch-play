# 不太灵的女巫 V48｜综合型童话养成

以 V47 完整项目为基础，保留原有25份美术素材、森林主线、花房订单、墨团每日陪伴、魔法研究台与 moonlightV3 存档。

## V48：森林今日生态
- 森林每天按日期轮换生态天气：薄雾、晴夜、细雨、萤光夜。
- 森林探索界面显示当天生态、实时昼夜阶段和季节。
- 天气会影响对应地点的材料收获与奇遇概率。
- 夜晚/黄昏会小幅提高森林奇遇概率。
- 萤光夜探索萤火桥有机会遇见稀有月翅蝶；夜晚探索月影水潭有机会遇见星鳞鱼。
- 首次发现稀有生物会记录到森林发现记录，并获得相应材料奖励。
- 天气按日期稳定，不依赖后台计时器；旧存档兼容，无需重开。
