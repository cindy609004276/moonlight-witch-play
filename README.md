# 不太灵的女巫 · 月光工坊（公开试玩站）

这是《不太灵的女巫》公开试玩站仓库。完整开发项目位于独立私人仓库。

## 部署游戏

1. 在 GitHub 网页的本仓库 Code 页面选择 **Add file → Upload files**，将单文件游戏 `index.html` 上传到仓库根目录，提交到 `main` 分支。
2. 进入 **Settings → Pages**，在 **Build and deployment** 下选择 **Deploy from a branch**。
3. 选择 `main` 分支与 `/(root)` 目录，点击 **Save**。
4. 等待 GitHub Pages 构建完成，访问 https://cindy609004276.github.io/moonlight-witch-play/ 。

**当前只有部署说明，不代表游戏已上线。** 必须先上传 `index.html` 并成功启用 Pages。

公开试玩站的网页代码和美术图片可被访问者查看；请勿上传私人文件、备份或密钥。
